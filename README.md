📱 PhonePe Transaction Analytics Dashboard

This project is a data analytics dashboard designed to monitor and analyze transaction performance on the PhonePe platform. It helps identify transaction trends, service-wise contribution, and failure patterns to support data-driven decision making.

🔍 Key Features

📅 Date Range Filter for year-long transaction analysis

💳 KPI Cards:

Total Transactions

Successful Transactions

Failed Transactions

Total Transaction Amount

📊 Service vs Amount Analysis

Loans

Insurance

Money Transfer

Recharge & Bills

📈 Monthly Transaction Amount Trend

🧩 Failed Payment Reason Breakdown:

Server Error

Wrong PIN

Insufficient Balance

Wrong Information

Bank Denied

📌 Insights Provided

Identification of high-revenue services

Monthly growth and decline patterns

Transaction success vs failure ratio

Common causes of payment failures

Data Visualization & Dashboarding
